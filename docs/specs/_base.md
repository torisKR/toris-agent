## Runtime baseline

- Node `>=22`, ESM only (`"type": "module"`), TypeScript 5.7, `moduleResolution: NodeNext`.
- **All relative imports MUST use explicit `.js` extensions** (NodeNext ESM), e.g. `import { x } from './x.js'`.
- Every package: `src/index.ts` is the only public entrypoint (barrel export).
- Tests: `vitest`, colocated as `src/**/*.test.ts`.
- Each package `package.json` uses this exact shape:

```jsonc
{
  "name": "@toris/<name>",
  "version": "0.1.0",
  "private": true,
  "type": "module",
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": { ".": { "types": "./dist/index.d.ts", "default": "./dist/index.js" } },
  "scripts": {
    "build": "tsc -p tsconfig.json",
    "typecheck": "tsc -p tsconfig.json --noEmit"
  }
}
```

And this exact `tsconfig.json`:

```jsonc
{
  "extends": "../../tsconfig.base.json",
  "compilerOptions": { "rootDir": "src", "outDir": "dist" },
  "include": ["src/**/*"],
  "exclude": ["src/**/*.test.ts"]
}
```

Workspace deps are declared as `"@toris/schemas": "workspace:*"`.

## Package graph (dependencies flow downward only — no cycles)

```
schemas   (no deps)

storage   -> schemas
workspace -> schemas
verifier  -> schemas
providers -> schemas

```

## Canonical IDs & paths

- IDs are opaque strings: `run_<26-char ulid-ish>`, `task_<...>`, `prj_<...>`, `sess_<...>`, `apr_<...>`, `evt_<...>`.
  Generated by `newId(prefix)` from `@toris/schemas`.
- Home dir resolution (from `@toris/schemas`): `torisHome()` returns `$TORIS_HOME` or `~/.toris`.
  - `torisHome()/config.yaml` — user config
  - `torisHome()/toris.db` — SQLite
  - `torisHome()/runs/<runId>/` — receipts, logs, artifacts
  - `torisHome()/worktrees/<runId>/<taskId>/` — writer worktrees
  - `torisHome()/daemon.sock` — supervisor unix socket (Windows: named pipe `\\.\pipe\toris`)
  - `torisHome()/daemon.json` — `{ pid, socket, version, startedAt }`

## Rules every implementer must follow

1. **Immutability**: repository `update()` and all state transitions return new objects. Never mutate inputs.
2. **Errors**: no silent catch. Throw typed errors or return `{ok:false, reason}`. User-facing messages must be actionable.
3. **Secrets**: every log/event/receipt path runs through `redact()` from `@toris/verifier`.
4. **Files**: 200–400 lines typical, 800 max. Functions < 50 lines. Split aggressively.
5. **Tests**: colocated `*.test.ts`, AAA pattern, descriptive names. Target 80%+ on your package's logic.
6. **No network in tests.** Use `mockAdapter()`.
7. Do not edit files outside your assigned package directory.
