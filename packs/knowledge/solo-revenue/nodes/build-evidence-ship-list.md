# Build → evidence → ship → list

Skip a step and the next session has to reconstruct it from chat.

1. **Build** — smallest paid-path change
2. **Evidence** — tests, screenshot, receipt, or device capture
3. **Ship** — tag, store track, or named production deploy
4. **List** — update the store listing, changelog, or landing page

If you cannot point at step 2, you are still on step 1.
