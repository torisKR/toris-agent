# Receipts, not vibes

A run is not done because an agent said so. It is done when your lint / test / build pass, and the receipt shows the exit codes.

- `toris receipt <runId>` is the artifact
- `--dry-run` still produces a plan; it is not evidence of a ship
- A fail verdict holds auto-apply
