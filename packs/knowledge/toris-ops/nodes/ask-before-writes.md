# Ask before L3 writes

Secretary files are durable. Do not dump a session into MEMORY.md or tacit notes because the model found it convenient.

- USER.md is facts about the human
- MEMORY.md is this machine / this product
- A procedure belongs in a node or a tacit note after a verified run
- `/reflect` proposes; it does not write until you accept
