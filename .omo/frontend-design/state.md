## Design read

Toris Studio is a Korean-first local creator operations room. It should feel calm and cinematic, not like a generic admin dashboard. The loop is list, inspect, edit, render, verify, review. Risky actions stay separate from ordinary editing.

## Interaction model

- Persistent left rail for the review queue and local status.
- Media-first center canvas with a 9:16 preview.
- Right inspector for copy, render settings, quality evidence, and guarded actions.
- Timeline and evidence rows appear when a content item is selected.
- Keyboard focus is visible; reduced motion disables nonessential transitions.

## Visual tokens

- Near-black canvas, graphite panels, thin cool borders.
- Warm ivory text, muted slate secondary text.
- Coral for active creation, green for verified quality, amber for review, red for destructive or failed states.
- Compact Korean UI typography, larger editorial headlines, and tabular metadata.
