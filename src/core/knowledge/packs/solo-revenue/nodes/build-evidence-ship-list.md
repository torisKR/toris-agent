# Build → evidence → ship → list

The one-person loop. Skip a step and the next session has to reconstruct it from chat.

1. **Build** — smallest paid-path change (`ship-small`)
2. **Evidence** — tests, screenshot, receipt, or device capture
3. **Ship** — tag, store track, or production deploy you can name
4. **List** — update the store listing, changelog, or landing page so a stranger can find the change

If you cannot point at step 2, you are still on step 1.
