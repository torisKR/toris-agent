# 1인 개발 수익화 루프

한 사람이 제품을 만들고, 증거로 확인한 다음, 출시하고, 목록에 올리는 루프. English is fine in nodes; Korean labels stay because that is how the operator thinks about the work.

Use this domain when the question is "how does this ship as a product I can charge for?" rather than a one-off code change.

## When to use

- First paid listing, itch/Play/web launch
- Turning a weekend build into a store presence
- Deciding what evidence belongs on the public page

## Anti-jobs (하지 말 것)

- 가짜 리뷰, 가짜 다운로드 수
- 출시 없이 랜딩 페이지만 다듬기
- 증거가 없는 "완성됨" 선언
