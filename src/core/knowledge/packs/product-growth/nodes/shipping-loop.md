# Shipping loop

Growth work that never ships is a diary. The loop is:

1. **Build** the smallest coherent change
2. **Evidence** — tests, screenshots, receipts, before/after
3. **Ship** — store, web, or git tag
4. **List** — update the public listing or changelog so the change can be found

`ship-small` is the builtin habit for step 1. Do not open a listing rewrite until step 2 exists.
