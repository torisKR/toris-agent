# SEO and GEO loop

Diagnose from evidence, prioritize by impact, implement only when authorized.

1. Inspect the live site **and** the repository. Neither view is complete alone.
2. Capture crawl, render, on-page, intent, and provenance baselines.
3. Cluster terms by user intent, not spelling variants.
4. Fix blockers (indexation, canonicals, contradictory robots) before copy polish.
5. GEO complements useful pages: explicit entities, direct answers, provenance, stable headings.
6. Create or update `llms.txt` only when requested.
