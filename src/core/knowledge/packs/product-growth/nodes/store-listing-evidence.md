# Store listing from evidence

A store listing is a product surface, not a brochure. Every claim in the title, subtitle, and description should be visible in a screenshot or a receipt from the running app.

- Map keywords to actual features, not aspirational ones
- Screenshots show the job the user came to do
- Localization follows shipped UI strings, not a marketing wish list
- Do not fabricate ratings or "featured in" lines
