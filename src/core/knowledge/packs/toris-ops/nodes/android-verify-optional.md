# Android verify is optional except when you claim a device fix

`adb` missing is a doctor **WARN**, never a failed `toris` install. Terminal chat and `toris run` work without an SDK.

When you *do* claim a mobile UI fix, capture a screenshot or say adb is missing. Install an APK with `toris android install <apk>`.

`toris android status|devices|screenshot|logcat`
