# Android verify is optional except when you claim a device fix

`adb` missing is a doctor **WARN**, never a failed `toris` install. Studio, chat, and `toris run` work without an SDK.

When you *do* claim a mobile UI fix, capture a screenshot or say adb is missing. `install` stays CLI-only.

`toris android status|devices|screenshot|logcat`
