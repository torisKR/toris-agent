# Ask before knowledge writes below L3

How we actually save secretary facts: the model may *propose* a USER.md line, a MEMORY.md fact, or a tacit note any time. It may *write* them unattended only at L3+. Below that, Toris asks. `/reflect` and `toris knowledge reflect` never write unless the operator passes `--write` or `accept`.
