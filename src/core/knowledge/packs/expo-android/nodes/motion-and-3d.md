# Motion and 3D on Expo

Interactive design is allowed. Unbounded particle systems on a phone are not.

- Prefer Reanimated / Skia worklets over React re-renders for the hot path
- Load 3D only when the screen is the 3D screen
- Provide a reduced-motion path
