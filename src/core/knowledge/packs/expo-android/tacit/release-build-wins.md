# Release build wins over Expo Go

How we actually verify Expo on Android: Expo Go is a convenience for layout. Performance, permissions, and navigation-bar insets are judged on a release (or at least preview) build. If they disagree, believe the release build and write the note here so the next session does not relearn it.
